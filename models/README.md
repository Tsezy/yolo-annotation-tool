# TSEZY 本地模型目录

请把 Ultralytics YOLO 目标检测模型文件放在这个目录中，文件扩展名必须为 `.pt`。

推荐选择：

- `yolo11n.pt`：速度最快、占用最低，适合先测试网站流程。
- `yolo11s.pt`：速度和识别效果更均衡。
- `yolo11m.pt`：识别能力更强，但需要更多显存和运行时间。
- `best.pt`：你使用自己的数据训练完成后产生的自定义模型，实际项目最推荐使用。

放入模型后刷新网页，模型会自动出现在“检测模型”下拉框中。

注意：应下载目标检测模型，不要下载分类、分割或姿态模型。文件名通常不应包含 `-cls`、`-seg` 或 `-pose`。
